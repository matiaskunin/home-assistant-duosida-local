# Contributing

Run all repository checks and include tests for behavior changes. Hardware
reports must identify the exact model and firmware but redact device IDs, MACs,
IP addresses and serial numbers. Clearly label hypotheses and physically
verified behavior.

Contributions are licensed under `GPL-3.0-only`.

Physical reports must use the matrix template, state the exact model and
firmware, include repeat counts, and remove device IDs, serial numbers, MAC and
IP addresses before submission.
